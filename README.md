# StockSense

An inventory management system for tracking stock across warehouses: receipts, delivery orders, internal transfers, and adjustments, all backed by a stock ledger.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Supabase (Postgres + Auth)

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in Supabase project URL + anon key
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
